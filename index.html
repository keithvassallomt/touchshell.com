Install

From extensions.gnome.org

One-click install. Recommended for most users on GNOME 49 or 50.

From source

git clone https://github.com/keithvassallomt/touchshell.git
cd touchshell
./scripts/pack.sh
gnome-extensions install --force \
  dist/touchshell@touchshell.com.shell-extension.zip

Wayland session only. Log out and log back in after installing.
